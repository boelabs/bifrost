## Configure a deployment

Send this body to `POST /admin/deployments` with an operator credential. Replace the example
credentials and choose a model available to your provider account. See
[Creating deployments](/docs/creating-deployments) for the shared configuration fields.

```json
{ "publicModel": "minimax", "adapterKey": "minimax", "upstreamModel": "MiniMax-M2", "credentials": { "apiKey": "..." } }
```

## Behavior and limitations

- **Credentials**: `apiKey` only. No `baseUrl` needed — defaults to `https://api.minimax.io/v1`.
- **Default transport**: Chat Completions.
- Catalog: `src/adapters/minimax/catalog.json`.
