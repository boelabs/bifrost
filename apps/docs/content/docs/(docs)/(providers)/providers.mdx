Choose an adapter for the provider and operation you need, then create a deployment with its
`adapterKey`, upstream model, and credentials. The adapter handles protocol translation; its
catalog supplies known model capabilities and pricing.

## Choose an adapter

The transport column describes the upstream protocol. Your application still uses Bifrost's
public API. OpenRouter currently supports reranking only.

## Configure the connection

Adapters with a built-in upstream host do not require `baseUrl`. `openaicompatible`, Azure OpenAI,
and Azure Foundry require `baseUrl` because the operator chooses the target endpoint.

`GET /admin/operations` returns this same adapter list live, including required credential keys and
which operations/transports each adapter actually implements.
